## 1. Núcleo compartilhado (`src/lib/ia-importacao.ts`, funções puras, sem React)
- `dividirEmLotes(texto, maxChars = 5000)`: divide em lotes cortando só em fim de linha (preferindo linha em branco); nunca parte uma linha ao meio; texto vazio devolve `[]`. Uma linha maior que `maxChars` vira um lote sozinha.
- `extrairJsonArray(resposta)`: tira cercas de markdown, acha o primeiro `[` e o último `]`, faz `JSON.parse`; se a resposta vier cortada (JSON incompleto), recupere os objetos completos que vierem antes do corte em vez de falhar tudo e devolva `{ itens, truncado: true }`.
- `normalizarNome(s)`: minúsculas, sem acento, sem pontuação, espaços colapsados (igual à normalização usada em `normalizarPergunta` se já houver uma reutilizável).
- `casarClinicas(nomesDaIA, clinicas)`: `clinicas` = lista de `{ id, nome_regiao, regiao }` (as de `tipo = 'clinica_amor_saude'`). Casa por igualdade normalizada com `nome_regiao`; senão por `nome_regiao` contido no texto ou o contrário (mínimo de 4 letras, para não casar "Centro" com tudo quando houver ambiguidade: se mais de uma clínica casar por contenção, **não case** e devolva o nome em `naoEncontradas`). O texto "todas", "todas as clínicas" ou "todas as unidades" vira todas as clínicas. Devolve `{ ids: string[], naoEncontradas: string[] }`, sem duplicar ids.
- `jaExiste(nome, existentes)`: comparação por `normalizarNome`.
- `rodarEmLotes(lotes, chamar, aoProgredir)`: roda os lotes **em sequência** (nunca em paralelo, para não estourar a cota de IA), junta os itens, avisa progresso ("Lote 2 de 5") e, se um lote falhar, **mantém o que já veio** e devolve também a lista de lotes que falharam (para o admin tentar de novo só esses).
- Testes novos em `tests/ia-importacao.test.ts` (estilo dos outros: `node:test`): lotes (corte em linha, linha gigante, vazio), JSON cercado por markdown, JSON truncado, casamento de clínica (igual, parcial único, ambíguo, "todas", acento), `jaExiste`.

## 2. Regras de IA válidas para as quatro abas
- **Nunca inventar.** Preço, média de referência, link e tempo de espera só saem se estiverem escritos no texto colado; senão `null`. Diga isso no prompt de sistema, em frase própria.
- Valores em reais como número com ponto decimal (aceite "R$ 1.234,56" do texto, mas a IA devolve número).
- O prompt de sistema vai por `simulatorChat` com `ADMIN_ASSISTANT_MODEL`, como hoje. Uma chamada por lote (seção 1), nunca uma por item. Mostre "Lote N de M" no botão enquanto roda.
- Na prévia: cada linha com a caixinha de marcar (como hoje) e **abrir para editar todos os campos** (linha expansível; mesmos componentes de campo do modal manual). Itens que **já existem** (por `jaExiste`) vêm **desmarcados** com a etiqueta "Já existe" (não sobrescreva nada existente; a importação só cria). Itens com clínicas não encontradas mostram a etiqueta "Clínicas para conferir" e a lista dos nomes que não casaram.
- Ao importar item com clínica não encontrada, salve `clinicas_pendente: true` (Consultas, que já tem esse campo) para cair na marcação "Revisar" que já existe; nas demais abas apenas mostre o aviso no toast final ("N itens com clínicas para conferir").
- Importação sequencial, item a item (como hoje); se um item falhar, continue com os outros e mostre no fim quantos entraram e quais falharam.
